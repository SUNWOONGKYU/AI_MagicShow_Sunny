■ 3. 9-c·d·e (팀메이트 역할/상태/색상) 구현 방식

  데이터 소스:
    - 역할: ~/.claude/teams/<team>/config.json 의 .members[].agentType
    - 상태: ~/.claude/teams/<team>/inboxes/<name>.json (멤버 inbox)
            + .../inboxes/team-lead.json (lead inbox 응답)

  상태 추론 로직:
    - 미독 메시지(read:false) 존재          → 작업중 (노랑)
    - 마지막 lead→teammate > 마지막 응답    → 작업중 (노랑)
    - 30분 내 응답 있음                     → 완료    (초록)
    - 그 외                                 → 대기    (회색)

  표시 예:
    👥 buzzlab-1 [TL-DA-S3(general/대기), TL-OP-C2(general/작업중)]

■ 4. 6-h (Hook 발동 표시) 구현 방식

  제약: Hook 발동은 transcript JSONL에 기록되지 않음.
  해결: 별도 hook-logger.js를 모든 hook event에 등록해
        /tmp/claude-statusline/hooks_<sess>.log 에 한 줄씩 기록.
        statusline은 최근 3초 이내 발동된 event만 표시.

  로그 형식: <epoch>\t<event_name>\t<tool_name>
  자동 회전: 200줄 초과 시 마지막 100줄 유지

  settings.json 에 추가된 hook-logger 등록:
    - UserPromptSubmit (기존 skill-trigger 다음)
    - PreToolUse       (기존 Agent matcher 다음, 별도 그룹)
    - PostToolUse      (신규)
    - Stop             (신규)
    - SessionStart     (신규)
    - PreCompact       (기존 export-session-to-wiki 다음)

  표시 예:
    🔧 ▶ Bash echo "test" Hook(PreToolUse,PostToolUse)

■ 5. 색상 규칙 (최종)

  ctx ≥ 80% / Rate ≥ 70%   : 빨강
  ctx ≥ 50% / Rate ≥ 50%   : 노랑
  그 외                    : 초록
  모델명                   : Bold + Bright Yellow (눈에 띔)
  디렉토리                 : Bold + Cyan
  git dirty                : 노랑
  git clean                : 초록
  git branch               : 마젠타
  도구 종류 / 인자         : 청록 / 흰색
  서브에이전트             : 노랑
  Hook 발동                : Bright Magenta (신규)
  팀이름                   : 마젠타
  팀메이트 작업중          : Bright Yellow
  팀메이트 완료            : Bright Green
  팀메이트 대기            : Gray
