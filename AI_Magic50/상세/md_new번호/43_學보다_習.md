# 43. AI는 공부 대상이 아니라 익힘의 대상이다 — 學보다 習

## 한 줄 정의

AI는 책상에서 강좌·문서로 **학(學)**하는 대상이 아니라, 매일 손으로 굴려 부딪치며 **습(習)**하는 대상이라는 — 본 시리즈 50개 전체를 관통하는 학습 철학.

## 왜 이 노하우가 중요한가

본인 누적 운용에서 가장 흔히 보는 시간 낭비가 **AI를 책으로 공부하려는 사람**이다. *"Claude Code 강좌 100시간 들어보겠습니다"* / *"프롬프트 엔지니어링 책 5권 읽고 시작할게요"* 식의 접근. 이게 왜 안 되는가 — AI는 매주 모델·도구·기능이 바뀌고, 책에 적힌 내용은 출간되는 순간 이미 구버전이다. 더 본질적으로, AI는 **사용자 본인의 작업 컨텍스트와 결합되어야** 효용이 나는 도구이지, 사용자와 분리된 일반 지식 체계가 아니다.

본인 누적 운용이 가르쳐 준 것: **강좌 100시간보다 실전 1시간이 낫다.** 본 시리즈 50개 노하우 전체가 *읽어서* 아니라 *부딪쳐서* 도출된 것이다. 스무고개(#1)도, SAL Grid(#3·#13)도, MBO(#12)도, DID Loop(#45)도 모두 책에 없던 것들이 **매일 손으로 굴리던 중에** 나왔다. 학(學)은 도구를 알게 하고, 습(習)은 도구를 자기 것으로 만든다. AI는 후자에서만 효용이 폭발한다.

왜 AI가 유독 공부보다 연습이 더 강력한가 — 3가지 구조적 이유가 있다. **첫째, AI는 비결정적**이다. 같은 입력에도 다른 출력이 나오므로 "이 prompt를 외우면 이 결과가 나옵니다" 식 공식이 성립하지 않는다. 손으로 굴려보며 응답 분포를 체득하는 수밖에 없다. **둘째, AI는 사용자 컨텍스트 의존적**이다. 본인 코드베이스·데이터·작업 습관과 결합되어야 효용이 나오므로 일반화된 학습 자료는 본인에게 적용될 때 효용이 급락한다. **셋째, AI는 빠르게 변한다**. 매주 모델·도구·기능이 바뀌어 책은 출간 즉시 구버전이 된다. 이 세 특성이 결합되어 AI 활용은 교육학자들도 **암묵지(tacit knowledge)**로 분류한다 — 책·강좌로 전수 불가능하고 직접 부딪쳐 손에 익혀야 하는 영역.

## 핵심 개념

논어 첫 구절 *學而時習之 不亦說乎* — **학(學)과 습(習)은 한 쌍**이다. 둘 중 하나만 있으면 반쪽이다.

| 축 | 학(學) | 습(習) |
|----|-------|-------|
| 활동 | 읽기·듣기 | 직접 굴리기 |
| 매체 | 책·강좌·문서 | 터미널·실제 작업 |
| 산출 | 머리 속 지식 | 손에 익은 감각 |
| 검증 | 시험·퀴즈 | 작업 결과물 |
| 시간 비용 | 가성비 낮음 (구버전 위험) | 가성비 폭발 |

**본인 학·습 비율 권장**: 학 10% / 습 90%. 학은 *어디에 무엇이 있는지* 지도를 머리에 그리는 정도면 족하다. 디테일은 습에서 채워진다.

**누적 운용은 곧 시간 자산**: 매일 충분히 손에 굴리면 몇 달~1년 단위로 노하우가 쌓인다. 이 시간을 강좌로 채웠다면 노하우 한 개도 안 나왔을 것이다.

## 실전 사용법

**1단계** — *강좌 등록·책 구매 충동*이 들 때 1분만 멈춰라. 그 시간에 **터미널 열고 prompt 한 줄 던지는 게** 더 나은 학습이라고 자문한다.

**2단계** — *모르는 기능 발견* → 문서 정독 X → **30분 안에 그 기능을 쓰는 작은 작업 1개**를 즉석에서 만들어 시도. 망해도 좋다. 망한 경험이 책 한 챕터보다 강력하다.

**3단계** — *오류 발생* → 검색·문서 의존 최소화 → **AI에게 직접 물어보고**, AI 답을 토대로 다시 시도. 오류 → 시도 → 오류 → 시도 사이클이 가장 빠른 습득 경로다 (#30 AI 오류 인정·창발과 짝).

**4단계** — *주 1회 손에 익은 패턴 정리*. 학(學)은 여기서 만들어진다. 습이 누적되면 자기 패턴이 보이고, 그 패턴을 글로 정리하면 그것이 *살아있는 학*이다 (본 시리즈 50개가 정확히 이렇게 만들어졌다).

**5단계** — *남에게 가르치기* — 가장 강한 습. 가르치려면 자기 패턴을 언어화해야 하고, 언어화 과정에서 빈 곳이 드러난다 (강의·유튜브 영상 제작이 본인 핵심 습 메커니즘).

**본인 운용 패턴**: 매일 30개 인스턴스를 굴리며 손에 익은 패턴은 매주 1~2개씩 본 시리즈에 추가됐다. 강좌·책으로 만든 것 0개, 손으로 만든 것 50개.
