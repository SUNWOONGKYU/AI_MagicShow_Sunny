# 42. 공사용 삽질/추수용 낫질 개선방안을 연구하지 말고 포크레인/트랙터 운전 연습하기

## 한 줄 정의

도구의 점진 개선이 아니라 **차원이 다른 도구로의 패러다임 전환**에 시간을 투자하라는 본 시리즈 50개 전체를 관통하는 핵심 메시지.

## 왜 이 노하우가 중요한가

본인이 누적 운용을 굴려보고 가장 절실히 느낀 것은 — **삽질을 아무리 잘해도 포크레인 한 시간에 못 미친다**는 사실이다.

주변에서 가장 많이 보는 풍경: 엑셀 함수 100개 외우기, 워드 단축키 마스터하기, 검색 키워드 잘 짜기, ChatGPT 프롬프트 1,000개 모음 외우기. 이것이 다 **삽질·낫질의 개선방안 연구**다. 손에 익은 도구를 1.2배 빠르게 만드는 데 1년을 쓴다.

같은 1년에 Claude Code 운전을 익히면 작업 처리량이 **20배~100배**가 된다. 본인 미니 풀스택 5시간 제작(#25)이 그 증거다. 옛날 같으면 한 달 걸릴 일이 5시간이다. *(산출 근거: 본인 #25 미니 풀스택 5시간 vs 종래 1인 개발 명세서 1주+와이어 3일+코딩 2주 ≒ 한 달 사이클 비교 — 작업 종류에 따라 20배~100배 폭 발생)*

이 마인드셋이 없으면 #48 WiKi_LLM, #22 SVG 자산화, #11 Hooks, #37 Worktree 같은 인프라 투자가 다 "굳이 왜?"가 된다. 마인드셋이 먼저, 도구 선택이 나중이다.

단, 본 노하우의 핵심은 **"도구를 바꿔라"가 아니라 "당신의 역할을 바꿔라"**다. 노동자 → 운전자/지휘자로의 정체성 전환. 본 시리즈 50개가 일관되게 #14 소대장, #31 30개 운용, #16 Sub-agents 메인, #12 MBO PO를 강조하는 이유가 여기 있다. 사용자는 더 이상 일하는 자가 아니라 부리는 자다.

## 핵심 개념

**도구 패러다임의 3 계층**

| 계층 | 비유 | AI 시대 사례 | 시간 투자 회수율 |
|------|------|---------------|------------------|
| 1단계 도구 | 삽·낫 | 워드·엑셀·메모장 | 1배 (정체) |
| 2단계 도구 | 손수레·예취기 | ChatGPT 앱·Claude 앱 | 3~5배 |
| 3단계 도구 | **포크레인·트랙터** | **Claude Code + SAL Grid + 30개 운용** | **20~100배** |

본인 운용 철학:

1. **1단계는 버려라** — 더 잘하려고 노력 금지
2. **2단계는 보조로만** — Claude 앱은 #32대로 브레인스토밍·문구에만
3. **3단계에 시간 투자** — Claude Code · 스킬 자산화 · 워크플로우 자동화

이 프레임이 정확히 #44 "문서화는 나중에"·#32 "앱 vs Code"·#31 "30개 운용"·#10 "헤드리스 자동화"의 마인드셋 토대가 된다.

또 하나의 핵심은 **"연습"**이라는 단어. 엑셀 함수 100개는 머리로 외우는 **소비형 지식**(한 작업에 한 번 쓰고 끝)이지만, Claude Code 운전은 손에 익는 **누적형 기능**이다. 한 번 익힌 CLAUDE.md 작성·MBO 사이클·Plan Mode 운영 패턴은 이후 모든 작업에 자동 적용되고, #48 Wiki에 누적되고, 가르치면 #38 외부 자산이 된다. 1시간의 연습이 평생 자산이 된다는 점이 1·2단계 도구 학습과 결정적으로 다르다.

## 실전 사용법

**1단계 — 본인 작업 도구를 1·2·3 계층으로 분류**
지난 일주일 시간 사용 로그 보고 80% 이상이 1·2단계에 있으면 적신호.

**2단계 — 1단계 작업 한 가지 완전 폐기**
예: 엑셀 매크로 학습 중단. 같은 작업을 Claude Code + Python으로 옮기는 데 2주 투자.

**3단계 — 3단계 도구 한 가지 깊게 익히기**
본인 권장 입문 순서:
1. Claude Code 설치 + #33 CLAUDE.md 세팅
2. #4 Plan Mode 익히기
3. #12 MBO 한 사이클 굴려보기
4. #25 미니 풀스택 5시간 도전
5. #22 SVG 자산화 → #11 Hooks → #37 Worktree

**4단계 — 익힌 것을 #48 Wiki에 누적**
다음 작업이 자동으로 빨라지는 구조 만들기.

**5단계 — 다른 사람에게 가르치기**
본인은 ax-on.net에 정리·공유. 가르치면 자기 이해가 깊어지고, 동시에 #38 외부 발굴의 역방향 — 본인이 외부 자산이 된다.

**자주 빠지는 함정**:
- "지금 쓰는 도구도 안 익숙한데..." → 익숙해질수록 갈아타기 어려워진다. **빨리** 갈아타라.
- "포크레인 면허가 비싸 보여서..." → Claude Code Max 요금이 본인 시급 1시간 분이다. 한 작업이 시간 단축 1회면 본전.
- "삽이 더 정밀하던데?" → 정밀도가 필요한 1%는 포크레인 옆에 삽 두면 된다.
