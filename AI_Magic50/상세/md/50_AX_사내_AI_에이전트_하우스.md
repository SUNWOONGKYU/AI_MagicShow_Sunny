# 50. AX를 위한 기능적 방법 — 사내 AI 에이전트 하우스 구축

## 한 줄 정의

AX(AI Transformation)는 외부 SaaS 도입이 아니라 **각 업무 단위마다 사내 전용 AI 에이전트를 한 칸씩 짓고**, 그것들을 한 지붕(통합 인덱스 페이지) 아래 모은 **사내 AI 에이전트 하우스**로 결실을 맺는다는 기능적 방법론.

## 왜 이 노하우가 중요한가

AX 컨설팅 현장에서 가장 흔히 보는 실패는 두 가지다. **첫째, "ChatGPT 회사 계정 깔아드리면 끝"** — 도구만 깔고 업무 흐름에 안 박힌다. **둘째, "거대 통합 플랫폼 한 방"** — 1~2년 걸리는 거대 프로젝트로 가다가 도중 좌초.

본인이 KD엔지니어링 AX 컨설팅에서 정착시킨 방법은 정반대다 — **업무 단위로 잘게 쪼개서, 각각을 하루~며칠 만에 굴러가는 작은 에이전트로 만들고, 그것들을 한 인덱스 페이지(`KD_AI_Tools_index.html`)에 올린다.** 9개 시범 에이전트(관리 3 + 엔지 3 + 입찰 3)가 그 하우스의 첫 9개 방이다.

작은 방 한 칸이 굴러가야 다음 방을 짓는 동기가 생긴다. **하우스는 한 번에 짓는 게 아니라 한 칸씩 입주시키며 짓는다.** 이게 #49(學보다 習)의 조직 버전이다.

## 핵심 개념

**3축 × 3개 = 9칸 시범 하우스 (KD엔지니어링 사례)**

| 축 | 업무 도메인 | 에이전트 사례 |
|----|----|----|
| **관리** | 백오피스·인사·법무 | 계약서 AI 검토 / 최적 인력 배치 / 회의록 자동 작성 |
| **엔지** | 설계·시공·검사 | 설계안 자동 생성 / CAD 도면 자동 검토 / 드론 균열 자동 감지 |
| **입찰** | 영업·제안·수주 | 나라장터 자동 스캔 / 제안서 초안 보조 / 유사 실적 분석 |

각 칸은 동일한 **표준 구조**를 갖는다:

1. `README.md` — 개요·해결 문제·기반 오픈소스·구현 방법·구현 현황
2. 실행 스크립트 (`*_gen.py`) — LangChain/Docling/RAGFlow/CrewAI 등 오픈소스 조합
3. 최신 산출물 (`*_latest.html`) — 실제 돌아간 결과물
4. 인덱스 페이지 진입 카드 — 한 줄 설명 + 진입 링크

**기능적 방법 4단계**

```
[1] 업무 흐름 분해     — 회사의 실제 업무를 10~20개 단위로 잘게 쪼갠다
[2] 1개 시범 에이전트   — 가장 가성비 높은 1개를 골라 1~3일 안에 굴러가는 상태 도달
[3] 인덱스 페이지 게시  — 단일 HTML에 카드 1장 추가 (KD_AI_Tools_index.html)
[4] 2~10번째 입주      — 같은 패턴 반복, 9칸~20칸까지 확장
```

**핵심 원칙: 작아도 좋으니 굴러가야 한다.** 미구현 상태의 거대 설계서보다 어설퍼도 돌아가는 작은 스크립트 한 개가 백 배 낫다.

## 실전 사용법

**1단계 — 업무 흐름 매핑**: 회사 핵심 업무 흐름을 종이 한 장에 그린다. 관리·엔지·입찰처럼 3~5개 축으로 나누고, 각 축마다 반복되는 업무를 5~10개씩 뽑는다. 이 단계에서 "이건 AI가 해도 되겠다" 후보가 30~50개 나온다.

**2단계 — 가성비 1순위 선정**: 30~50개 후보를 두 기준(반복 빈도 × AI 적합도)으로 점수 매겨 **상위 3~9개**만 남긴다. 첫 입주는 한 개부터.

**3단계 — 표준 폴더 구조 채택**: `에이전트사례/{축}-{번호}_{이름}/` 형태로 통일. 내부에 `README.md` + 실행 스크립트 + 최신 산출물 3개 파일이 들어간다. 이 구조가 통일되어야 인덱스 페이지가 자동 생성 가능하다.

**4단계 — 오픈소스 조합 명시**: 각 에이전트 README에 "기반 오픈소스" 표를 명시한다 (예: LangChain ★73k / Docling ★37k / RAGFlow ★78k). 무엇 위에 만들어졌는지 투명해야 사내 엔지니어가 손댈 수 있다.

**5단계 — 인덱스 페이지(`{회사}_AI_Tools_index.html`)에 카드 추가**: 새 에이전트가 굴러가면 즉시 인덱스에 카드 한 장 추가. 카드에는 (1) 한 줄 설명 (2) 최신 산출물 링크 (3) README 링크 3가지만. **인덱스가 곧 하우스의 입구이자 정문이다.**

**6단계 — AX Culture 3요소 결합**: 기술만으로는 안 된다. **나눔(Sharing) + 선의의 경쟁(Healthy Competition) + 격려·보상(Encouragement & Reward)** 이 3요소가 같이 도입되어야 하우스가 살아 움직인다 (별도 노트: `AX_Culture_3요소.md`).

**본인 운용 패턴**: KD엔지니어링은 9개 카드로 시작해서 분기마다 3~5개씩 입주시키는 패턴. 1년이면 20~30칸 하우스가 된다. 처음부터 30칸 짓겠다고 했으면 0칸으로 끝났을 것이다.
