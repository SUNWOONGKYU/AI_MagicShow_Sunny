HTML + Vercel 신속 배포

공유하고 싶은 내용을 HTML로 만들어 GitHub Pages가 아닌 Vercel로 배포 — URL 아는 사람만 접근 가능 · 검색엔진 차단 · 로그인 불필요
🛠 Skill: /vercel-private-url-배포

📌 핵심 정의

GitHub Pages는 공개 인덱싱 + 한글 폴더명 자유라는 장점이 있지만 검색엔진 노출이 강제된다. 본 스킬은 Vercel CLI 직접 배포로 noindex 메타 + robots.txt + Deployment Protection 해제까지 자동화하여 "URL을 아는 사람만 접근, 검색엔진은 차단"이라는 사적 공유 모드를 1분 안에 실현한다. 옵션으로 비밀번호 게이트(고정 / Supabase DB 필드)까지 지원한다.

🏗 아키텍처 — 8 Step Pipeline

🔐 비밀번호 옵션 3종

없음 (기본)

정적 HTML 그대로 배포. URL만 알면 진입. noindex + robots.txt로 검색엔진 차단.

고정 비밀번호

Next.js 앱 자동 스캐폴딩. PASSWORD 환경변수 1개로 게이트. middleware로 /reports/* 보호.

Supabase DB 검증

예: 생년월일 8자리 매칭. 슬러그 → DB id 매핑 → 필드 비교. API route + cookie 인증.
