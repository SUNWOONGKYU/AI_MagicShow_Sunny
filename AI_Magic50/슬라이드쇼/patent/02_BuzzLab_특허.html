다중 LLM 다차원 발언 ID 기반
전문가 페르소나 토론 시스템

3개 이상의 분야별 전문가 페르소나 AI가 참여(반드시 Devil's Advocate 포함)하여 5단계 토론으로 방안 제시 — 이를 시스템화한 특허
📜 특허 출원 · BuzzLab

📌 발명의 핵심

단일 LLM 응답의 편향·환각·일면적 판단을 다관점 토론으로 보정한다. 3+ 전문가 페르소나 + Devil's Advocate(반대측 옹호자) 필수 참여 구조에서 5단계 토론을 수행하고, 각 발언에 다차원 발언 ID(페르소나·차수·발화유형·근거단계)를 부여하여 토론 과정의 재현성·감사가능성을 확보한다. rubric_score 100점 도달까지 최대 5 Cycle 수정 루프로 자기 수렴.

🎯 5단계 토론 Phase

1

입장 표명

각 페르소나 초기 입장

2

상호 반박

DA 주도 반대 논거

3

증거 제시

외부 게이트 통과 자료

4

합의 도출

Judge 평가 + 가중 종합

5

최종 권고

BPI + DA_penalty 반영

🛠 핵심 차별화 메커니즘

(a) 다차원 발언 ID

Persona×Cycle×Type×Evidence

모든 발언에 4차원 ID 부여로 토론 흐름·결정 근거를 사후 감사 가능하게 함

(b) DA 필수 참여

Devil's Advocate 무력화 방지

BPI 공식에 DA_penalty 항 도입 — DA가 동조하거나 형식적 반대만 하면 점수 자동 차감

(c) Judge 분리

Self-Grading 폐쇄 루프 차단

토론 참여 페르소나와 평가 Judge를 별도 Subagent로 분리, 자기 평가 편향 차단

(d) 외부 게이트

rubric 100 ≠ 종료 보증

도메인별 외부 표준(KIPO·빌드·접근성·재무 일관성 등) 통과를 필수 종료 조건으로 추가

(e) 의미 일관성 게이트

명칭↔요약서↔본문 3중 검증

약자 정의·발명 명칭·요약 핵심 키워드 3중 의미 일관성 자동 검증 (DID 특허 v2.0 결함 사례 반영)

(f) 창발 이벤트 포착

5종 강제 액션 매핑

예상 못한 합의·갈등·재정의·근거 역전·관점 융합 5종 이벤트를 감지하여 강제 액션으로 활용
