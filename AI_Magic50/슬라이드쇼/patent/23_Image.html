멀티 모델 이미지 종류별 제작 프로세스

Photo · Chart · Architecture 3트랙으로 자동 라우팅 — 단일 진입점 /image-기본에서 의도를 판단해 적합한 도구·모델로 분기
🛠 Skill: /image-기본 (Master Dispatcher)

📌 핵심 정의

"이미지" 한 단어 안에 사실적 사진·인포그래픽·시스템 구조도 등 본질적으로 다른 작업이 묶여 있다. 이걸 한 모델로 통일하려 들면 사진은 어색하고 다이어그램은 부정확해진다. 본 스킬은 의도를 먼저 판별하고, 각 트랙별로 최적화된 도구·모델 조합을 호출한다. 기존 3개 독립 스킬(/ai-image-기본, /create-image-기본, /architecture-svg)을 그대로 보존하면서 위에 얇은 라우터를 얹은 구조다.

🏗 아키텍처 — 1 Router + 3 Track

🎯 3 Track 분기

Photo Track

사실적 사진 · AI 일러스트 · 로고 · 스티커
  • 외부 멀티모델 (Gemini · GPT Image · DALL-E)
  • 마스킹 편집 · 멀티 레퍼런스 지원
  • 품질 모드: 4단계 깔때기 (아래 참조)
  • 독립 스킬: /ai-image-기본

Chart Track

다이어그램 · 표 · 차트 · 대시보드 · 플로우차트
  • Claude가 직접 코드 생성
  • Mermaid · HTML/CSS · SVG · Pillow
  • 한글 폰트 (malgun.ttf) 자동 처리
  • 독립 스킬: /create-image-기본

Architecture Track

V50 / V60 시스템 구조도 (전용 스타일)
  • 컬러팔레트 고정 (라이트모드 13컬러)
  • BuzzLab · PoliticianFinder 통일 스타일
  • 섹션 구조화 + 표준 마커·그라데이션
  • 독립 스킬: /architecture-svg
