SUNNY AI MAGIC · #28

구조화된 디지털 산출물(SDA) 자동 수집·선별 및 다차원 신뢰성 평가에 의한 정량적 등급 부여 — 추천 시스템 및 방법

작업결과물에 대해서 수시로 4종의 품질관리 스킬을 실행하여 완성도 높이기 — 이를 시스템화한 특허
📜 특허 출원 · V9 (만장일치 97.6점)

📌 발명의 핵심

GitHub·GitLab·npm·PyPI·HuggingFace·n8n.io·Docker Hub·Terraform Registry 등 공개 저장소에 게시된 구조화된 디지털 산출물(Structured Digital Artifact, SDA — 7유형)을 자동으로 수집·선별하고, 5개 신뢰성 축에 대해 결정론적 공식에 의한 N단계 정량적 등급을 부여하며, 그 등급과 사용자 요구사항·벡터 유사도에 기반하여 적합한 산출물을 추천하는 시스템 및 방법.

SDA 7유형: 소스코드 / AI 스킬·에이전트 설정 문서 / 프롬프트 템플릿 / 워크플로우 정의 문서 / Config-as-Code / IaC / 정책 코드

🎯 5개 신뢰성 평가 축

1

보안

OWASP·CWE 기반 취약점 검출

2

품질

코드 메트릭·테스트 커버리지

3

유지보수성

구조·복잡도·문서화 수준

4

라이선스 적합성

상업적 사용·재배포 가능성

5

안전성 위협도

악성·위험 패턴 5단계 등급

🛠 7대 차별화 메커니즘

(a) 연결 시점 검증

실시간 재취득·재평가

원본 저장 없이 위치·메타데이터만 저장, 사용자 요청 시점에 재취득·재평가하여 허용 편차 초과 시 자동 차단·대체 추천

(b) LLM 자동 분기

로컬 vs 외부 API 자동 선택

기밀성·동의·자원·정확도 요구에 따라 자동 분기. 비공개·NDA·미동의 산출물은 로컬 경로 강제

(c) 맞춤형 제작

요구 분해 + 보완 + 재등급

사용자 기능 요구를 단위로 분해, 컴포넌트 자동 선정·조합, 누락 기능 AI 코드 생성으로 보완 후 재등급

(d) 검증 가능 신뢰성 지시

5축 등급 동시 렌더링

g₁~g₅ 및 종합 등급 G_total을 UI에 동시 표시, 취득 트리거 전 다차원 평가 가능

(e) 자원 보호 게이팅

서명된 일회성 토큰

광고 노출·결제·구독·토큰 버킷 등 검증 가능 이벤트 기반 signed gate-bound URL 발급, prefetch leakage 방지

(f) 다층 등급 (Master)

Trust × Safety × Utility

3개 등급을 결합한 Master 종합 등급, Safety 임계 초과 시 Trust·Utility와 무관하게 결정론적 강등 (Safety 오버라이드)

(g) Safety-aware 정렬

위험 산출물 자동 후순위

Master 1차 키 + Trust·Safety·Utility 보조 키 + 연결 시점 재검증 결과로 추천 정렬, Safety 위험 산출물 결정론적 후순위 강등

⚡ 차별화된 신규성 (KIPO 변리사 패널 만장일치 [A] 97.6점)

항목기존 추천 시스템 (GitHub, npm, HuggingFace)본 발명
