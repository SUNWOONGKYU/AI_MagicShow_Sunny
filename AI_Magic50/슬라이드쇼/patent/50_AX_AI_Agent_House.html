SUNNY AI MAGIC · #50

AX를 위한 기능적 방법 — 사내 AI 에이전트 하우스 구축

AX(AI Transformation)는 외부 SaaS 도입이 아니라, 각 업무 단위마다 사내 전용 AI 에이전트를 한 칸씩 짓고, 그것들을 한 지붕(통합 인덱스 페이지) 아래 모은 사내 AI 에이전트 하우스로 결실을 맺는다.
🏠 KD엔지니어링 AX 컨설팅 실전 사례 (9칸 시범 하우스)

📌 핵심 정의

AX 컨설팅 현장에서 가장 흔한 실패는 두 가지다. "ChatGPT 회사 계정 깔아드리면 끝"(도구만 깔고 흐름에 안 박힘) 과 "거대 통합 플랫폼 한 방"(1~2년 짜리 거대 프로젝트 좌초). 본 방법은 정반대 — 업무 단위로 잘게 쪼개서 각각을 하루~며칠 만에 굴러가는 작은 에이전트로 만들고, 한 인덱스 페이지에 입주시킨다.

작은 방 한 칸이 굴러가야 다음 방을 짓는 동기가 생긴다. 하우스는 한 번에 짓는 게 아니라 한 칸씩 입주시키며 짓는다. 이게 #43(學보다 習)의 조직 버전이다.

🏗 KD엔지니어링 9칸 시범 하우스 — 3축 × 3개

① 관리축 (Management) — 백오피스·인사·법무

관리-01

계약서 AI 검토

계약서를 자동 파싱하여 핵심 조항 추출 + 지체상금율·하자담보기간 등 위험 조항 탐지. 검토 누락 위험 차단.
Docling ★37k / LangChain ★73k
관리-02

최적 인력 배치

기술자 등급·전공·가용성을 PuLP 선형최적화로 최적 배치. 책임기술자 중복 + 과부하 + 자격 미매칭 방지.
PuLP / pandas ★45k
관리-03

회의록 자동 작성

회의 텍스트(또는 음성 전사)에서 논의사항·결정사항·담당자별 액션아이템을 자동 구조화. 표준화 + 지연 감지.
Jinja2 / Whisper ★75k

② 엔지축 (Engineering) — 설계·시공·검사

엔지-01

설계안 자동 생성

설계 조건(구조형식/하중/지반) 입력 → RAG로 유사 설계 사례 검색 → LLM이 설계 초안 생성. 기술사 검토 전제.
LangChain ★73k / RAGFlow ★78k / CrewAI ★23k
엔지-02

CAD 도면 자동 검토

DWG/DXF/PDF 도면을 자동 분석하여 누락 항목·기준 미달·오류 탐지. 납품 직전 야근 방지.
ezdxf / OpenCV ★80k / Vision LLM
엔지-03

드론 균열 자동 감지

드론 사진을 YOLOv8 모델이 자동 분석하여 균열·박리·손상 위치 탐지. 95%+ mAP 정확도. 수백 장 수작업 검토 해소.
Ultralytics YOLOv8 ★35k / Roboflow

③ 입찰축 (Bidding) — 영업·제안·수주

입찰-01

나라장터 자동 스캔

나라장터 OpenAPI로 입찰공고를 실시간 수집, KD 업무 키워드로 0~99점 자동 채점, D-Day 카운트다운 관리.
data.go.kr OpenAPI / Airflow ★37k
입찰-02

제안서 초안 보조

프로젝트 정보 입력 → 표지·목차·수행계획·투입인력·BIM/드론 특수사항까지 포함한 전문 제안서 HTML 자동 생성.
Jinja2 / CrewAI ★23k
입찰-03

유사 실적 분석

과거 수행 프로젝트 DB를 TF-IDF 인덱싱하여 새 입찰 키워드로 유사 실적 TOP5 자동 추출. 자격 요건 확인 시간 단축.
TF-IDF / RAGFlow ★78k / LlamaIndex ★39k

🏛 표준 구조 — 모든 방이 동일한 4요소

구성요소역할
README.md개요·해결 문제·기반 오픈소스·구현 방법·구현 현황
실행 스크립트 (*_gen.py)LangChain·Docling·RAGFlow·CrewAI 등 오픈소스 조합
최신 산출물 (*_latest.html)실제 돌아간 결과물 (인덱스 페이지에서 직접 열림)
인덱스 카드한 줄 설명 + 진입 링크 — KD_AI_Tools_index.html

🔁 기능적 방법 4단계

1

업무 흐름 분해

회사 실제 업무를 10~20개 단위로 잘게 쪼갠다

2

1개 시범 에이전트

가성비 1순위를 골라 1~3일 안에 굴러가는 상태로

3

인덱스 게시

단일 HTML에 카드 1장 추가 ({회사}_AI_Tools_index.html)

4

2~10번째 입주

같은 패턴 반복, 9칸~20칸까지 확장

핵심 원칙: 작아도 좋으니 굴러가야 한다. 미구현 거대 설계서보다 어설퍼도 돌아가는 작은 스크립트 한 개가 백 배 낫다.

🌱 AX Culture 3요소 — 하우스를 살아 움직이게 하는 엔진

기술만으로는 안 된다. 다음 3요소가 같이 도입되어야 하우스가 살아 움직인다.

나눔 (Sharing)

AI로 얻은 지식·노하우·프롬프트를 전사적으로 공유. 한 사람의 발견이 열 사람의 역량으로.

선의의 경쟁

누가 더 효과적인 프롬프트를 설계했는가, 누가 더 창의적 활용 사례를 만들었는가. 서로 끌어올리는 경쟁.

격려·보상

우수 사례 발굴자를 인정·보상. 나눔과 경쟁의 선순환 엔진 작동.

"AX is Culture. Not Technology." — AX의 승패는 기술이 아니라 문화에서 갈린다.
