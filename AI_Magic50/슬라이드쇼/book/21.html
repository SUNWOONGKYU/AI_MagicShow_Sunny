SUNNY AI MAGIC 50 · #21

대량 검색 시 토큰비를 줄이려면 네이버·구글 검색 활용하기

Claude·ChatGPT는 검색 엔진이 없고 외부 서비스를 빌려 쓰니 네이버·구글을 통해 검색
G3 · 실행 방법 C타입

한 줄 정의

생성형 AI에게 직접 웹 검색을 시키면 크레딧 폭탄을 맞는다. Claude·ChatGPT는 자체 검색 엔진이 없어 외부 검색 서비스를 빌려 쓰고 그 비용이 사용자에게 전가되기 때문. 검색은 검색 전문인 네이버·구글에서 사람이 직접 처리하고, AI에는 정제된 결과만 투입해 토큰·크레딧을 절감하는 운용 원칙.

왜 이 노하우가 중요한가

본인 누적 운용에서 가장 큰 비용 누수가 발생하는 지점이 AI에게 "찾아봐"를 시키는 순간이다. 이유는 단순하다 — AI마다 검색 인프라 구조가 다르고, 검색 엔진이 없는 AI는 외부 서비스를 호출당 과금으로 빌려 쓴다.

AI사별 검색 인프라 차이

AI 검색 인프라 비용 구조
Gemini 자체 Google 검색 (Google Search Grounding 무료 제공) 추가 비용 없음
Perplexity 자체 검색 엔진 구축 추가 비용 없음
Claude 검색 엔진 없음 — 외부 web_search 도구 연동 호출 1회당 $0.01 별도 과금
ChatGPT 검색 엔진 없음 — Bing 연동 호출당 별도 과금

→ 한쪽은 자기 인프라를 그냥 쓰는 거고, 다른 쪽은 남의 검색을 빌려 쓰고 그 요금이 그대로 사용자 크레딧에서 빠진다. 같은 "검색" 명령어를 쳐도 백엔드 구조가 다르다.

참고: Claude·ChatGPT는 API 미사용 구독 모델에서도 웹 검색을 시키면 월 사용량이 일반 대화 대비 훨씬 크게 차감된다. "구독이라 무료"가 아니다.

특허 출원서 한 건을 위해 선행기술 50건을 Claude로 검색하면 web_search $0.01 × 50 = $0.50 + 결과 페이지 토큰화 비용. 30개 동시 운용 환경에서 인스턴스 셋만 검색을 돌려도 5시간 Rate Limit이 한 시간 만에 소진되고 크레딧도 같이 녹는다.

반면 네이버·구글 검색창에 사람이 직접 키워드 넣고 결과 제목·요약만 추려서 AI에 던지면 같은 정보를 1/20 토큰 + 검색 호출 과금 0으로 처리할 수 있다. 컨텍스트도 깨끗하게 유지된다.

원리 한 줄: 검색은 검색 전문 엔진의 일, AI는 정제된 결과로 사고만 — 도구별 전문성으로 역할 분리.

핵심 개념

검색 비용 = (쿼리 횟수 × 외부 검색 호출 과금) + (결과 페이지 토큰 × 인스턴스 수)

Gemini·Perplexity는 첫 번째 항이 0이라 본 챕터 규칙이 덜 절박하지만, Claude·ChatGPT는 두 항 모두 사용자 부담 이라 절감 효과가 극대화된다.

토큰 절감 3원칙:

단계 AI 수행 사람 수행
키워드 도출 O (AI 강점) -
검색 실행 X (비쌈) O (네이버·구글)
결과 1차 필터 X O (제목·요약 보고)
본문 정독·종합 O (AI 강점) -

핵심은 AI는 사고 엔진, 검색은 사람의 눈으로 역할 분리. 사람이 5초 만에 거를 수 있는 무관한 결과를 AI에게 토큰으로 태워 거르게 하는 것은 낭비다.

대안 도구: - 네이버: 한국어 자료, 블로그·카페·뉴스 - 구글: 영문 논문·GitHub·StackOverflow·해외 특허 - 구글 학술검색: 논문 PDF 직링크 - KIPRIS·Google Patents: 특허 검색은 반드시 전용 사이트 - DuckDuckGo: 익명 검색·중복 제거

실전 사용법

1단계 — AI에 키워드 5~10개 추출 시키기 "SAL Grid 개발방법론 관련 선행기술 검색용 키워드 10개 뽑아줘. 영문·한글 혼합."

2단계 — 사람이 네이버·구글에 직접 검색 키워드별 상위 10건 제목·URL 메모장에 복사. 본인은 클라우드 동기화 폴더의 임시 .txt에 모은다.

3단계 — AI에 1차 필터 시키기 "이 50건 중 SAL Grid 3차원 좌표 관점에서 관련성 높은 것 10건 골라."

4단계 — 사람이 10건 본문 PDF·HTML 다운로드 AI 내장 검색이 아니라 직접 다운로드. 토큰 0.

5단계 — AI에 본문 투입해 비교·종합 이때부터 AI 강점 발휘. 차별점·약점·창발 포인트 추출.

본인 운용 결과: 특허 10-2026-0009425 SAL Grid 출원 시 선행기술 80건 검토를 본 방식으로 처리. Claude 내장 web_search 추정치 대비 토큰비 약 1/15 + 검색 호출 과금 $0.80 절감으로 완료. 같은 작업을 #10 트랙터 운전 패러다임과 결합하면 한 번 익혀둔 검색 루틴이 매 작업마다 비용을 깎는다.

주의: 시급한 단답·실시간 정보(주가·환율 등)는 AI 내장 검색이 더 빠르다. 또 Gemini는 자체 검색이라 비용 부담이 거의 없으니 가벼운 단발 검색은 Gemini에 위임하는 것도 선택지. 대량·심층 검색에서 Claude·ChatGPT를 쓸 때 본 방식 적용이 가장 효과적.
